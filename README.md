## Intalacion

Ejecutar el siguiente comando

```bash
  npm install
```
Instalar yarn como un metodo alterno al iniciar el servidor
```
yarn install
```

<hr>

### Compilar el proyecto
Usando: 
```
yarn run serve
```
o
```
npm run serve
```
